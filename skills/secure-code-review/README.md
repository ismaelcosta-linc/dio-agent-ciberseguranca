# Secure Code Review

Skill de revisão de segurança de código desenvolvida como
especialização do DIO Agent para o desafio Santander/DIO.

## Objetivo

Auxiliar estudantes e desenvolvedores na identificação,
compreensão, correção e validação de vulnerabilidades em código.

## Funcionalidades

- Análise de código e identificação de práticas inseguras.
- Classificação de vulnerabilidades usando CWE e OWASP.
- Associação contextual com técnicas MITRE ATT&CK.
- Avaliação de impacto, probabilidade e gravidade.
- Orientação para correções simples e eficazes.
- Validação das mitigações por testes locais autorizados.
- Relatório com evidências e comparação antes/depois.

## Diferencial

A skill não se limita a identificar vulnerabilidades.

Seu procedimento inclui a verificação das correções e a
comparação dos resultados anteriores e posteriores à mitigação,
contribuindo para um processo educativo de DevSecOps.

## Utilização

O DIO Agent pode aplicar a habilidade quando o estudante
solicitar uma revisão de segurança de código.

Exemplo de solicitação:

"Analise a segurança deste código Python, identifique os
riscos e me ajude a validar as correções."

A execução de testes e alterações depende de autorização
e deve ocorrer em ambiente controlado.

## Finalidade

Projeto exclusivamente educacional, desenvolvido para
